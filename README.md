# HybridTools_TesterSel

## Paper
Espitia-Buitrago, et. al. (2026) [link]

## Overview
Tester selection optimisation in inbred hybrid breeding programs

## How to reproduce results
1. Clone the repo
2. Install dependencies (list )
3. Run main.R

## Structure
- GlobalParameters/: simulation parameters
- Section2_*/: scripts for optimal number of testers under the assumption of homogeneous variance and independence among combining ability components
- Section3_*/: scripts for single tester or tester set selection under the assumption of heterogeneous variance and covariances between combining ability components

## Authors
Paula Espitia-Buitrago, Daniel Tolhurst Roslin Institute, University of Edinburgh
