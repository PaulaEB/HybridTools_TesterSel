# HybridTools_TesterSel

## Paper
Espitia-Buitrago, et. al. (2026) [link]

## Overview
Tester selection optimisation in inbred hybrid breeding programs

## How to reproduce results
1. Clone the repo
2. Install dependencies (list )
3. Run main.R

## Structure
## Structure
- functions_TesterSel.R: Shared functions
- S1_GlobalParameters.R: simulation parameters 
- S2_homogeneousCAvariances.R: optimal number of testers under the assumption of homogeneous variance and independence among combining ability components
- S3_heterogeneousCAvariances.R: single tester or tester set selection under the assumption of heterogeneous variance and covariances between combining ability components
- S4_representativeness.R: representativeness metrics and site-specific weights
- S5_testerprofiles.R: GCA vs SCA slopes and accuracy evaluation
- S0_appendix.R: supplementary analyses
